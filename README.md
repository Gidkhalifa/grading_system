\# Student Score Management System



A simple Python program to manage student scores.



\## Features

\- Add students with names and grades

\- View students and their letter grades

\- Calculate average score

\- Remove a student by name

\- Exit the program



\## Grading Scale

\- 80+ = A

\- 70–79 = B

\- 60–69 = C

\- 50–59 = D

\- Below 50 = F



\## How to Run

Run the Python file using:



python high.py
